# Vision and Scope (Business Requirements)

## Project Identity
- **이름:** omk (oh my knowledge)
- **목적:** AI 에이전트가 사용자의 로컬 환경에서 지식을 복리로 축적하고 탐색할 수 있도록 돕는 '독립형 로컬 지식 금고(Standalone Local Knowledge Vault)'.
- **핵심 목표:** 에이전트가 대화 컨텍스트를 잃더라도, 로컬에 저장된 과거의 지식을 직/간접적으로 연결하여 '교차 맥락 선제적 노출(Proactive Grounding)'을 수행하도록 지원하는 것.
